# Simple Interest Calculator

## Introduction

This project contains a simple interest calculator written in Bash.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

Where:
- Principal = Initial amount
- Rate = Rate of interest
- Time = Time period

## How to Use

1. Run the `simple-interest.sh` script.
2. Enter the principal amount.
3. Enter the rate of interest.
4. Enter the time period.
5. The program calculates and displays the simple interest.

## Example

Principal = 1000
Rate = 5
Time = 2

Simple Interest = 100
